# QBCORE ONLY!!!

QBCoreのみサポートしてます。NPCにターゲットをあわせてNUIを開いて、QBCoreからcharinfo.firstname/lastname を更新する構成です。
NUIはViteで作成しています。バグってたら修正してください。

## 必要なスクリプト
qb-core,
ox_lib,
ox_target(qbターゲットでもいいです)

通知はokokNotify,ox_lib,qbcoreに対応しています。
